# Support
This project was made on a Win11 on ARM build, I can't promise your machine on a different architecture can run this project normally.

The buildx86 folder contains code and executables that only support Windows x86 devices

The build-Aarch64W contains code and executables that only support Windows on ARM64 devices

The build-Aarch64L conatins code and executables that only support Linux on ARM64 devices (Experiemental and only verified by WSL tests).
